# Day 1 — 2026-09-25

Scaffold plus a real OpenAlex smoke path. No claim schema, extractor, or judge.

## Shipped

- Installable `claimforge` package (`src/` layout), MIT license kept, pytest,
  and GitHub Actions for Python 3.11 and 3.12 on pull requests and pushes to
  `main`.
- Disk-cached GET client: URL-hash keys under `data/cache`, exponential
  backoff, retries on 429 and transient 5xx, and `Retry-After` when it parses.
- OpenAlex works search and `claimforge smoke-openalex` (default query
  `physics informed neural network`, `per_page=3`).
- Unit tests for cache keying and retries (mocked transport, plus a localhost
  check of the urllib transport). One live OpenAlex integration test that
  soft-skips on network errors and HTTP 429/5xx.
- README, architecture stub, and `.env.example`. Optional future
  `CLAIMFORGE_LLM_*` variables are comments only. No secrets are committed.

## Failed

- Nothing in the Day 1 scope failed its check. Local `pytest` passed the unit
  suite and the live OpenAlex test. `claimforge smoke-openalex` printed three
  works and exited 0.
- OpenAlex can still return 429 from the public pool. That is a skip for the
  integration test, not a broken cache or CLI.
- Claim extraction was not attempted. There is no schema to fail yet.
