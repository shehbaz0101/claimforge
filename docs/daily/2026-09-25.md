# Day 1 — 2026-09-25

Scaffold plus a real OpenAlex smoke path. No claim schema, extractor, or judge.

## Shipped

- Installable `claimforge` package (`src/` layout), MIT license kept, pytest,
  and GitHub Actions for Python 3.11 and 3.12 on pull requests and pushes to
  `main`.
- Disk-cached GET client: URL-hash keys under `data/cache`, exponential
  backoff, retries on 429 and transient 5xx, and `Retry-After` when it parses.
- OpenAlex works search and `claimforge smoke-openalex` (default query
  `physics informed neural network`, `per_page=3`).
- Unit tests for cache keying and retries (mocked transport, plus a localhost
  check of the urllib transport). One live OpenAlex integration test that
  soft-skips on network errors and HTTP 429/5xx.
- README, architecture stub, and `.env.example`. Optional future
  `CLAIMFORGE_LLM_*` variables are comments only. No secrets are committed.

# Day 2 — 2026-09-26

Claim schema and an abstract extractor. No evidence retriever and no judge.

## Shipped

- Strict `Claim` model (`id`, `text`, `source_work_id`, `source_title`,
  optional `confidence`, optional `claim_type` of factual / method / result /
  other). Extra fields are rejected. `model_dump(mode="json")` is the JSON form.
- Rule-based `extract_claims_from_abstract`: sentence split plus claim cues
  (`we show`, results, findings, demonstrates, evidence that, method phrases).
  No API key. Empty abstracts return an empty list.
- `extract_from_openalex_work` reads a string abstract or OpenAlex's
  `abstract_inverted_index`.
- Optional OpenAI-compatible LLM path behind `CLAIMFORGE_LLM_API_KEY` and
  `CLAIMFORGE_LLM_MODEL`. If either is unset, the LLM is skipped. A failed
  call falls back to the rules. Documented in `.env.example`. No secrets.
- `claimforge extract-claims --query "..."` fetches a few works with the Day 1
  client and prints claims as JSON. `smoke-openalex` still works.
- Unit tests use fixture abstracts and do not touch the network. One live
  OpenAlex extract check soft-skips on network errors and HTTP 429/5xx.

## Failed

- Nothing in the Day 2 scope failed its check. Local `pytest` passed the unit
  suite and the live OpenAlex tests. `claimforge extract-claims` printed JSON
  claims, and `claimforge smoke-openalex` still printed a work.
- Some OpenAlex works have a null abstract. Those records add no claims.
- Cue patterns miss sentences that do not look like results, methods, or
  simple factual statements. That is the heuristic.
- OpenAlex can still return 429 from the public pool. That is a skip for the
  integration test, not a broken client.
